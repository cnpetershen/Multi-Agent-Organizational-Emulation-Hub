## 0. 审计结论

已有：

- M3.7 `GET /api/promotions/:id/confirmed` 的完整 confirmed 交接；
- 真实 HTML 生成/文件写入能力（预览运行时的文件式交付、内容工作台页面）；

因此本轮发布范围明确为 **本地真实发布**：

- 生成本地正式发布 HTML + manifest；
- 由 MAOEH API 提供真实可访问 URL；
- 外部渠道 `external_wechat` 只记录 `unavailable`，不产生 URL/浏览量/成功记录；
- 不冒充外部平台发布。

## 1. 数据模型

`PublicationRecord`（planning store `publications`）：

```text
publicationId, companyId
promotionId, promotionVersion
executionId, planId, planVersion, approvalId
requirementId, requirementVersion
approvedBy/At, promotionConfirmedBy/At
sourceArtifacts[], taskIds[]
currentVersion, versions[]
```

`PublicationVersion`：

```text
version, status: draft|ready|publishing|published|partial|failed|cancelled
content{title,body,channels[],attachments[]}
checks[]
createdAt/updatedAt
confirmedAt/By
attempts[{attempt,requestedAt,requestedBy,results[]}]
publishedAt/By, publicPath
```

`PublicationChannelResult`：

```text
channel: local_page | local_manifest | external_wechat
status: published | failed | unavailable
resourceId, url, error, verifiedAt
```

- 最终发布内容版本独立于 M3.7 promotion；编辑/确认/发布不修改 promotion。
- 每次尝试追加，成功记录不被覆盖。

## 2. API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/publications` | 发布摘要列表 |
| POST | `/api/publications` | `{promotionId}`；只接受 confirmed promotion；同 promotion 幂等 |
| GET | `/api/publications/:id` | 版本、检查、尝试、结果 |
| GET | `/api/publications/:id/preflight` | 服务端发布前检查 |
| PUT | `/api/publications/:id` | `{baseVersion, patch}`；派生独立 draft |
| POST | `/api/publications/:id/confirm` | `{baseVersion, confirm:true}`；人类明确确认 |
| POST | `/api/publications/:id/publish` | `{baseVersion, confirm:true}`；执行本地发布 |
| GET | `/api/publications/:id/page` | 已发布本地 HTML 页面 |

## 3. 来源与发布前检查

- 只允许 M3.7 `status=confirmed` 的 promotion；
- promotion 必须仍能追溯到 M3.6 `action=approve` 的 approval；
- 检查：来源 confirmed、来源 approved、标题/正文非空、至少一个本机渠道、外部渠道授权状态；
- 打开页面/保存/读取 preflight 不会发布；
- 确认与发布都需要 `confirm:true`，是两次独立的人类动作。

---

## 4. 执行与幂等

- 发布前写入 `publishing`，再实际写文件；结果落库为 `published|partial|failed`。
- 同一 publication/version 已 `published`：重复请求返回原记录 `idempotent:true`。
- 同一进程并发：`publicationInFlight` 拒绝第二次。
- 进程重启后 `publishing` 记录可安全重试（无 in-flight 时允许重新执行，历史 attempt 保留）。
- `failed|partial` 可用同一版本重试，也可编辑新版本再确认；历史 attempts 不覆盖。
- 部分渠道成功：`partial`，每个 channel 分别记录 URL/error。
- 外部渠道：`unavailable`，无 URL；不伪造成功。
- 页面读取始终取最新 `published|partial` 版本，后续 draft 不会让已发布 URL 失效。

本地产物：

```text
<publicationDir>/publications/<publicationId>/v<version>/index.html
<publicationDir>/publications/<publicationId>/v<version>/manifest.json
```

`publicPath = /api/publications/<id>/page?v=<version>`。

## 5. Theater 事件

真实 `Document.*` 事件：

- `Document.PublicationDrafted`
- `Document.PublicationConfirmed`
- `Document.PublicationPublished`
- `Document.PublicationPartiallyPublished`
- `Document.PublicationFailed`

由真实发布记录生成，不是模拟消息；Theater `stage=release`，`stageBasis=event-type`。Theater 只读，不承担发布逻辑。

---

## 6. 七阶段闭环

发布记录保留：

- requirementId/version
- planId/version
- executionId
- approvalId
- promotionId/version
- taskIds/sourceArtifacts
- confirmedBy/At, publishedBy/At
- 本地页面/manifest URL

因此可从 publication 回溯需求、方案、执行、审批、推广与发布，不需要重新生成内容。

---

## 7. 边界

1. 无外部平台授权；只做本地真实发布。外部渠道记录 `unavailable`。
2. 不伪造浏览量、传播数据、发布 URL 或合作。
3. 本地页面由 MAOEH API 提供；不是公网托管，也未接入外部 CDN。
4. 单租户单 operator。
5. 无自动发布；每次都需人工确认。
